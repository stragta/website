01
Orientación

De una carpeta vacía a un sistema que deja huella

El taller no presenta un agente como una caja negra. Muestra una arquitectura sencilla: un perfil, unas entradas, tres responsabilidades especializadas, contratos de salida, validación y un dashboard que conserva el estado.

Contenido visible

La guía explica el razonamiento antes de pedir una acción. El lector puede entender el flujo sin descargar nada.

Prompts reutilizables

Los bloques están preparados para copiar, pegar, adaptar y volver a probar dentro de un proyecto local.

Fuentes separadas

Noticias, documentos, resultados e historial conservan su lugar para que la evidencia no se confunda con una inferencia.

Control humano

La persona confirma alcance, revisa advertencias y decide antes de publicar, programar o incorporar información institucional.

05
Antes de empezar

Preguntas frecuentes

¿Necesito tener un sistema de agentes?

No. La ruta desde cero parte de una carpeta local vacía. La base preparada sirve para llegar más rápido a la primera ejecución.

¿Los prompts se pueden copiar y pegar?

Sí. Cada prompt aparece como texto visible y tiene un botón de copia. Conviene leerlo y adaptar sus nombres, fuentes, permisos y zona horaria antes de ejecutarlo.

¿Los datos del demo son institucionales?

No. El paquete está preparado para practicar con documentos y noticias enlazados, pero no debe recibir información confidencial ni sustituir una evaluación de gobierno y seguridad.

¿Puedo pedir una adaptación para mi empresa?

Sí. La siguiente conversación puede centrarse en el caso de uso, los datos autorizados, las personas responsables y los criterios para validar un piloto.
