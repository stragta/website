Qué datos tratamos y para qué

Consultas de contacto

Tratamos el nombre, correo, empresa, servicio seleccionado y mensaje que facilitas para responder a tu consulta y realizar actuaciones solicitadas antes de una posible contratación. La base jurídica es el artículo 6.1.b del RGPD. Las comprobaciones antispam se basan en nuestro interés legítimo en proteger el formulario y el canal de comunicación, conforme al artículo 6.1.f.

Asistente de IA PACO

Si decides iniciar PACO, se procesan los mensajes que envías, un identificador aleatorio de sesión y datos técnicos limitados para responder preguntas sobre STRAGTA. Tu decisión afirmativa de iniciar el chat constituye la base jurídica conforme al artículo 6.1.a del RGPD. No incluyas información sensible o confidencial. PACO no toma decisiones con efectos jurídicos o de importancia similar.

Entrega del sitio

El sitio no usa analítica, rastreadores publicitarios ni cookies opcionales. GitHub Pages y otros proveedores de infraestructura pueden procesar direcciones IP y registros técnicos de solicitud para entregar y proteger el servicio.

Destinatarios y proveedores

  • Google Workspace y Apps Script para los formularios de contacto.
  • GitHub Pages para el alojamiento del sitio.
  • Railway para el alojamiento de la aplicación PACO.
  • OpenRouter y el proveedor del modelo seleccionado para la inferencia de IA. Cada solicitud de PACO pide a OpenRouter usar endpoints de retención cero y denegar la recopilación de datos por el proveedor.

Transferencias internacionales

Algunos proveedores pueden tratar datos fuera del Espacio Económico Europeo. Cuando corresponda, las transferencias se amparan en una decisión de adecuación, el Marco de Privacidad de Datos UE-EE. UU. o cláusulas contractuales tipo de la Comisión Europea. Puedes solicitar más información en el correo indicado.

Conservación

  • Consultas de contacto: hasta seis meses desde la última interacción, salvo obligación contractual o legal de conservación superior.
  • Memoria de sesión de PACO: hasta 30 minutos desde la inactividad.
  • Registros operativos de PACO: hasta seis meses y limitados a eventos agregados como idioma, etiquetas temáticas, longitud del mensaje y errores. STRAGTA no guarda el texto completo del chat en estos registros.

Tus derechos

Puedes solicitar acceso, rectificación, supresión, limitación, oposición y portabilidad cuando correspondan, o retirar el consentimiento para tratamientos futuros, escribiendo a stragta0@gmail.com. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos.
