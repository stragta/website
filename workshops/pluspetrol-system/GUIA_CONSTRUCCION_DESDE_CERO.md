# Construcción reproducible

1. Abre la carpeta en Work Local (Codex como alternativa).
2. Confirma modelo y herramientas web realmente disponibles.
3. Conserva arquitectura y deja vacías las entradas hasta investigar.
4. Lee AGENTS.md y preserva fuentes, perfil e historial.
5. Completa config/perfil.json con los ocho campos exactos.
6. Acuerda contratos de agentes, config y CONTRATOS.md.
7. Usa el motor stdlib para estado y validación, sin web propia.
8. Sirve el dashboard desde la raíz del sistema.
9. Planifica, aprueba, investiga en vivo, selecciona, documenta y consolida. Repite para comprobar continuidad.
10. Audita selección, apertura de fuentes, fechas, lectura efectiva, relaciones, inventario y modo de ejecución.

Consulta README.md para comandos y CONTRATOS.md para JSON. No se necesitan materiales preparados. Listo para uso local solo cuando el dashboard carga, contratos se validan, fuentes son trazables y la repetición no duplica registros; no es certificación institucional.
